From a resource row · Rename
Rename resourceChanges the last path part of /orders/{id}; children move with it.
Nothing is checked on rename doze-aws applies the new part as typed. It does not test it against the path-part rule or against a sibling's name, as the add dialog's calls are. Renaming to a name a sibling already has leaves two resources at one path, and the live tree answers from one of them.
A rename is live straight away: the old path no longer matches this resource.
