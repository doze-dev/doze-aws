Eight things in S3 ask before they act

Object row or panel · Delete
Delete “HRB-2026-04811.json”? This bucket is versioned, so a delete marker is added: the object leaves the list and its versions stay. Without versioning it is gone.
After it: the panel closes and the list redraws.
Bulk bar · Delete selected
Delete the 2 selected objects? One DeleteObjects request. On a versioned bucket each key gets a delete marker and keeps its versions.
After it: the list redraws without them.
A version · ✕
Permanently delete this version? This skips the delete marker. The version is gone for good, and the key's other versions stay. A version under retention or a legal hold is refused.
After it: the Versions list redraws.
Header · Delete bucket
Delete bucket “harbour-returns-labels”? It must be empty. Anything using the name afterwards gets NoSuchBucket.
Delete bucket
After it: back to the list. A bucket with anything left in it refuses.
Properties · Tags · ✕
Remove the tag “team”? Its value, checkout, goes with it. Other tags are not touched.
After it: the tag list redraws.
Properties · Notifications · trash
Stop notifying harbour-loyalty-points-prod? Objects written from now on no longer reach it. Messages already sent stay in the queue.
After it: the rule list redraws.
Properties · Static website · Disable
Disable website hosting? Requests to the site stop resolving. The objects stay.
After it: the card goes back to its Enable form.
Properties · Multipart uploads · trash
Abort the upload of “exports/2026-q3.csv”? Its 3 uploaded parts are discarded and the space is freed. Whoever started it cannot complete it.
After it: the uploads table redraws.
What does not ask Upload, New folder, Create bucket, Copy, Wire a notification, Add tag, Enable website, Save CORS, lifecycle and policy, Hold and Retain. Each is what you came to do or can be redone. Three deserve a plain word: Move removes the source key once the copy lands, Block public access turns off the moment its switch is flipped, and versioning turns off, which suspends it, the same way.
