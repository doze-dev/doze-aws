What a call to one of them getsnew
A family doze-aws recognises and does not model is answered 501 NotImplemented by name, rather than a bare 404 that reads like a routing bug. Your app sees it on the wire; the console has no control that sends one.
FamilyThe message
REST: domainnames, clientcertificates, vpclinks, sdktypes, models, requestvalidators, documentation, gatewayresponsesdoze-aws does not implement API Gateway <family>
REST: usagedoze-aws does not meter requests, so there is no usage to report or reset
REST: ImportApiKeysImportApiKeys reads a CSV of keys; create them one at a time with CreateApiKey
HTTP: WEBSOCKETdoze-aws does not implement WebSocket APIs; protocolType must be HTTP
HTTP: domainnames, vpclinksdoze-aws does not implement API Gateway v2 <family>: there is no DNS, TLS termination or VPC locally
HTTP: JWTdoze-aws does not implement JWT authorizers: there is no identity provider locally to issue or verify tokens
HTTP: service integrationdoze-aws does not implement the AWS service integration <subtype>; use an AWS_PROXY integration to a function
HTTP: routeresponses, integrationresponsesdoze-aws does not implement route responses: an HTTP API route answers with its integration's response
Two that are not a 501 A COGNITO_USER_POOLS authorizer is 400 BadRequestException, with no user pool locally. A non-proxy AWS integration saves and answers 500 when called.
